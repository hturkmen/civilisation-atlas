# Görev devir kayıtları

Her aktif görev için ayrı bir Markdown dosyası oluştur; [şablonu](../handoff-template.md) kullan. Dosya adı görev ve benzersiz çalışma ekini içersin. Ayrı araçların tek ortak kayıt dosyasını eşzamanlı düzenlemesi gerekmez.

Bu dizin hazırlanırken yeni yerel veri/arayüz görevi henüz başlatılmamıştı. Güncel sahiplik için açık PR dallarındaki kayıtları da oku; yalnız main dizinine bakmak yeterli değildir. Sırf bu README'nin eski olması işi sahipsiz yapmaz.

Durmuş işi devralınca mevcut görev kaydını koruyup gerçek durumunu güncelle. Aktif görev için ikinci kopya veya çelişkili sahiplik oluşturma. Tamamlanan kayıtlar geçmiş ve doğrulama izi olarak korunur. Gizli bilgi ve kullanıcı verisi ekleme.
