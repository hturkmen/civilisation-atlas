# P02-003 — bounded local package quarantine

16 Eylül 2026. Başlangıç main `9b6a0006a70dc1088e9f7bb71525d75c66829189`. Önceki PostGIS/import dilimiyle çakışmayan ayrı çalışma alanı. Kullanıcı talimatı gereği PR açılmadan doğrudan main teslimi. Kod commit'i `77b7dfee42cd617d5dfe4c18c04fbefcc7a16a58` GitHub üzerinden doğrulandı.

## Uygulama

- `0003_local_import_jobs.sql`: immutable yerel iş kaydı ve imported revision ilişkisi. `adapter_version` + `policy_version` + okunabilen input SHA ile aynı paket tekrarı ayırt edilir; karantina outcome ve sabit hata koduyla saklanır.
- `import-bundle.mjs`: yalnız mutlak yerel `.json`, regular file ve no-follow açılış; 8 MiB byte, 64 derinlik, 200.000 JSON düğümü, 100 kayıt, 50.000 vertex limitleri. JSON/contract/geometri/DB constraint hataları atlas import transaction'ı rollback sonrası karantinaya yazılır. Ağ, redirect, arşiv, symlink ve rastgele HTML/SVG yok.
- `export-local-bundle.mjs`: mevcut beş adayı ve ilgili entity/source/pin'leri repo dışı `0600` yeni dosyaya çıkarır; review/publication değiştirmez.
- Local runner artık ortak migration helper kullanır; eski `import:check` bellekte/ayrılmış dizinde çalışmaya devam eder. Yeni `import:bundle` ve `export:bundle` komutları dokümante edildi.

Karantina ham JSON'u, kullanıcı yolu veya ağ yanıtını saklamaz. Dosyanın tamamı byte bütçesinde okunabildiyse SHA-256; hata kodu ve gözlenen byte sayısı saklanır. 8 MiB üstü dosyada güvenli erken ret yapılır; tam dosya hash'i iddia edilmez.

## Kalan

Bu hâlâ worker/HTTP upload değildir. Production malware taraması, gerçek object storage, queue lease/heartbeat, native PostgreSQL/PostGIS staging, iki bağlantılı yarış, server-side auth/RLS, inceleyen onayı ve public release bekler. Aşırı büyük dosyada tam checksum/dedup üretmediği için aynı yanlış dosya tekrarları ayrı quarantine receipt oluşturabilir; bu bilinçli erken-ret davranışıdır, prod policy kararı değildir. Tarihsel geometri/kaynak/review uydurulmadı.

Son dosya bileşenindeki symlink reddedilir; üst dizinler yerel operatörün güven sınırıdır. Linux üzerinde doğrulandı; Windows symlink yetkileri ve gerçek Windows dosya okuma yarışı doğrulanmadı. Byte/vertex sınırları CPU timeout veya eşzamanlı iş kotası değildir. Uzak teslim önceki denemelerde otomatik onay incelemesinin kullanım limiti nedeniyle çalıştırılmadı; son denemede normal GitHub aracı başarılı oldu ve main HEAD yeniden okundu. Önceki teslim engeli artık tarihsel kayıttır.

Sonraki somut iş: bu yerel policy sonucunu güvenli worker job sözleşmesine bağlamak; lease/heartbeat, bounded retry ve worker süre bütçesini yerelde test etmek. Bu dilimin kodu ve kayıtları artık GitHub'da; yerel çalışma alanı devralmak için zorunlu değildir. Demo/runtime değişmedi, yeni yayın yok. Bu son teslim kaydı yalnız belgedir; test edilmiş kod değişmedi.
