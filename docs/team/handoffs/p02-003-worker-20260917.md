Yeni claim token alır; süresi geçmiş token yenilenemez. 30 saniye lease, 120 saniye mutlak deneme sınırı, en fazla 3 deneme, ilk/ikinci retry için 5/10 saniye gecikme. Terminal görev, kimlik ve olay geçmişi değiştirilemez. Receipt checksum/adaptör/politika/outcome eşleşmesi SQL'de aranır. PUBLIC tablo/fonksiyon yetkileri kapalıdır.

`apps/worker/import-tasks.mjs`: bounded file reader ile enqueue checksum'ı, çalıştırmadan önce checksum yeniden kontrolü ve eski worker'ın sonuç yazmasını engelleyen transaction. İş sonuç kaydı ile atlas içeriği aynı commit içindedir. Veri hatası quarantine; tanımlı geçici DB hataları retry; beklenmeyen hata/file mismatch failed. Eski worker yeni sahibin durumunu değiştiremez. Ham SQL hata metni, dosya yolu veya lease token'ı CLI çıktısına yazılmaz.

`worker:once` ayrı CLI; yalnız verilen dosyanın görevini bir kez işler. Scheduler veya provider eklenmez. Dosya DB'ye kopyalanmaz, operatör dosyayı erişilebilir tutar. Başarılı görevin aynı girdisi yeniden işlenmez. Migration helper 1–4 sürümlerini uygular; eski migration dosyaları ve web bağımlılıkları korunur.
